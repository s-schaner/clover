```tsx
interface SectionWrapperProps {
  id: string;
  theme?: 'dark' | 'light';
  className?: string;
  children: React.ReactNode;
}
```

Render a `<section>` element with:
1. `id={id}` — the anchor target
2. `className` combining:
   - `section-dark` or `section-light` based on `theme` prop (these classes are defined in `globals.css @layer components`)

Export as `default`.
