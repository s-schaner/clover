<task type="auto">
  <name>Task 1: Create Navigation component with scroll-spy and mobile menu</name>
  <files>components/layout/Navigation.tsx</files>
  <action>
Create `components/layout/Navigation.tsx` as a Client Component (`'use client'` at top).

**Imports:**
- `useState`, `useEffect`, `useRef`, `useCallback` from `react`
- `Link` from `next/link`
- `Menu`, `X` from `lucide-react`
- `clsx` from `clsx`
- `NAV_LINKS`, `COMPANY`, `NAV_HEIGHT_PX`, `SECTION_IDS` from `@/lib/constants`

**State:**
- `activeSection: string` initialized to `SECTION_IDS.HERO`
- `isMenuOpen: boolean` initialized to `false`

**Refs:**
- `menuButtonRef: useRef<HTMLButtonElement>(null)` — hamburger button for focus return
- `overlayRef: useRef<HTMLDivElement>(null)` — overlay container for focus trap

**useEffect 1: Scroll-Spy (IntersectionObserver)**
- Get all section IDs from `Object.values(SECTION_IDS)`
- Create `IntersectionObserver` with:
  - Callback: for each entry, if `entry.isIntersecting`, call `setActiveSection(entry.target.id)`
  - Options: `rootMargin: \`-${NAV_HEIGHT_PX}px 0px -55% 0px\``, `threshold: 0`
- For each section ID, call `document.getElementById(id)` and observe if element exists
- Cleanup: `observer.disconnect()`
- Dependency array: `[]` (mount once)

**useEffect 2: Body Scroll Lock**
- When `isMenuOpen` is true: `document.body.style.overflow = 'hidden'`
- When `isMenuOpen` is false: `document.body.style.overflow = ''`
- Cleanup: `document.body.style.overflow = ''`
- Dependency array: `[isMenuOpen]`

**useEffect 3: Focus Trap + Escape Key**
- Only active when `isMenuOpen` is true (early return otherwise)
- On open: find first focusable element in `overlayRef.current` using selector `'a[href], button, [tabindex]:not([tabindex="-1"])'` and call `.focus()` on it
- Keydown listener for:
  - `Escape`: close menu (`setIsMenuOpen(false)`), return focus to `menuButtonRef.current`
  - `Tab` / `Shift+Tab`: query all focusable elements in overlay, wrap focus from last to first (Tab) or first to last (Shift+Tab) using `e.preventDefault()` + `.focus()`
- Cleanup: remove keydown listener
- Dependency array: `[isMenuOpen]`

**handleNavLinkClick callback:**
- `useCallback(() => setIsMenuOpen(false), [])` — closes mobile menu when any nav link is clicked

**JSX Structure:**

```
<header> (fixed top-0 inset-x-0 z-50 h-[--nav-height] bg-surface border-b border-surface-border)
  <nav> (role="navigation" aria-label="Main navigation", flex items-center justify-between h-full px-[--section-padding-x] max-w-screen-2xl mx-auto)

    [Wordmark]
    <Link href="#hero"> with font-display font-semibold text-on-surface text-lg tracking-tight
      {COMPANY.name}

    [Desktop nav links]
    <ul> (hidden md:flex gap-8 list-none)
      {NAV_LINKS.map} each as <li>
        <Link href={link.href}>
          className computed with clsx:
            base: 'text-sm font-body transition-colors duration-base'
            active (activeSection === link.sectionId): 'text-on-surface font-medium'
            inactive: 'text-on-surface-muted hover:text-on-surface'
          aria-current={activeSection === link.sectionId ? 'true' : undefined}
          onClick={handleNavLinkClick}
          {link.label}

    [Hamburger button]
    <button> (ref=menuButtonRef, md:hidden, text-on-surface p-2)
      aria-label={isMenuOpen ? 'Close menu' : 'Open menu'}
      aria-expanded={isMenuOpen}
      aria-controls="mobile-menu"
      onClick: toggle isMenuOpen
      Icon: isMenuOpen ? <X size={24} /> : <Menu size={24} />

  [Mobile overlay — conditionally rendered when isMenuOpen]
  {isMenuOpen && (
    <div> (id="mobile-menu" ref=overlayRef role="dialog" aria-modal="true" aria-label="Navigation menu")
      className: "fixed inset-0 top-0 z-40 bg-surface flex flex-col items-center justify-center gap-8"

      [Close button] (absolute top-6 right-6)
        aria-label="Close menu"
        onClick: setIsMenuOpen(false), menuButtonRef.current?.focus()
        <X size={24} />

      [Nav links list]
      <ul> (flex flex-col items-center gap-8 list-none)
        {NAV_LINKS.map} each as <li>
          <Link href={link.href}>
            onClick={handleNavLinkClick}
            className="font-display text-3xl text-on-surface hover:text-on-surface-muted transition-colors duration-base"
            {link.label}
  )}
</header>
```

**Critical details from research:**
- The overlay is rendered INSIDE the `<header>` element — this means it inherits the header's z-50 stacking context and doesn't fight z-index battles
- `aria-current="true"` (not `"page"`) since these are anchor links on the same page
- Desktop links also get `onClick={handleNavLinkClick}` — harmless on desktop (menu is already closed) but ensures consistency
- The hamburger button shows X icon when menu is open but the overlay itself ALSO has a close button for clarity
- Initialize `activeSection` to `SECTION_IDS.HERO` so no nav link is highlighted on page load (Hero is not in NAV_LINKS)

Export as `default`.
