**Part A: Create HoverLift component**

Create `components/ui/HoverLift.tsx` as a `'use client'` component.

**Props interface:**
```typescript
interface HoverLiftProps {
  children: React.ReactNode;
  className?: string;
  scale?: number;  // default 1.025 (between 1.02-1.03 from CONTEXT.md)
}
```

**Implementation details:**

1. Import `motion` and `useReducedMotion` from `framer-motion`.

2. Guard with `useReducedMotion()` — when truthy, return a plain `<div>` with className and children. No scale, no transition.

3. When animation is active, use `motion.div` with:
   - `whileHover={{ scale }}` — scale up on hover
   - `transition={{ duration: 0.12, ease: [0.0, 0.0, 0.2, 1] }}`:
     - 120ms is within the "instant-feeling" 100-150ms range from CONTEXT.md
     - Ease matches `--ease-out` for a quick, natural deceleration
   - `style={{ willChange: 'transform' }}` — hint GPU to composite this layer (needed because `whileHover` elements are not initially animated, so framer-motion may not promote them automatically)

4. The component should NOT set `cursor: pointer` — that's the consumer's responsibility based on whether the child is a link/button.

**Part B: Add link-underline CSS utility to globals.css**

Add the following to `app/globals.css` inside the `@layer components` block (after the hero-pattern-draw rules added by Plan 03-01):

```css
.link-underline {
  position: relative;
  display: inline-block;
}

.link-underline::after {
  content: '';
  position: absolute;
  bottom: -1px;
  left: 0;
  width: 100%;
  height: 1px;
  background: currentColor;
  transform: scaleX(0);
  transform-origin: left center;
  transition: transform var(--duration-fast) var(--ease-out);
}

.link-underline:hover::after {
  transform: scaleX(1);
}

@media (prefers-reduced-motion: reduce) {
  .link-underline::after {
    transition: none;
  }
}
```

Key details:
- Uses `currentColor` so the underline matches text color in both dark and light sections
- `transform-origin: left center` means the line draws from left to right on hover
- On mouse leave, the line retracts back to the left (scaleX(0))
- `--duration-fast` (150ms) matches the "instant-feeling" hover speed from CONTEXT.md
- `prefers-reduced-motion` disables the transition (underline still appears on hover, but instantly)
- The underline is 1px tall, positioned 1px below the text baseline — thin and precise

**What NOT to do:**
- Do NOT use framer-motion for the link underline — CSS pseudo-element approach is simpler and avoids importing motion for a text decoration
- Do NOT use `text-decoration` — the draw effect requires a pseudo-element
- Do NOT set `cursor: pointer` on HoverLift — consumer's responsibility
- Do NOT animate `box-shadow` or `border` on HoverLift — scale-only per CONTEXT.md
