  <action>
Create `components/ui/GridPattern.tsx` as a `'use client'` component.

**Props interface:**
```typescript
interface GridPatternProps {
  theme: 'dark' | 'light';
  position?: 'corner-br' | 'corner-tr' | 'edge-right' | 'full';
  className?: string;
}
```

Default `position` to `'corner-br'` (bottom-right corner accent — research recommendation for consistent placement across all sections).

**Implementation details:**

1. Use `useId()` from React to generate a unique prefix for all SVG `<pattern id>` attributes. This prevents ID collision when multiple GridPattern instances render on the same page (Pitfall 3 from research).

2. Build a 4-level nested SVG `<pattern>` structure in `<defs>`:
   - Level 3 (finest): 5px tiles, strokeWidth 0.15px — barely visible, creates texture density
   - Level 2: 10px tiles, strokeWidth 0.3px — fills with level 3, adds own grid lines
   - Level 1: 20px tiles, strokeWidth 0.5px — fills with level 2, adds own grid lines
   - Level 0 (primary): 40px tiles (matches `--pattern-size`), strokeWidth 0.8px — most visible grid

   Each pattern uses `patternUnits="userSpaceOnUse"`. Each level fills a `<rect>` with the next-finer level's pattern, then draws its own L-shaped grid path: `d="M {size} 0 L 0 0 0 {size}"`.

3. The main SVG rect fills with the level-0 pattern: `<rect width="100%" height="100%" fill={url(#${id}-l0)} />`

4. Use `stroke="currentColor"` on all paths so the pattern inherits text color from its container (white on dark sections, black on light sections).

5. Wrap the SVG in a `<div>` with:
   - `className="absolute inset-0 overflow-hidden pointer-events-none"` (plus any passed className)
   - `aria-hidden="true"` (decorative, not accessible content)
   - `style={{ opacity, maskImage }}` where:
     - `opacity` reads from CSS custom property: `theme === 'dark' ? 'var(--pattern-opacity-dark)' : 'var(--pattern-opacity-light)'`
     - `maskImage` varies by position prop:
       - `corner-br`: `radial-gradient(ellipse 60% 70% at 100% 100%, black 30%, transparent 80%)`
       - `corner-tr`: `radial-gradient(ellipse 60% 70% at 100% 0%, black 30%, transparent 80%)`
       - `edge-right`: `radial-gradient(ellipse 50% 80% at 100% 50%, black 30%, transparent 80%)`
       - `full`: `radial-gradient(ellipse 80% 80% at 50% 50%, black 40%, transparent 100%)`

6. The SVG element itself: `<svg width="100%" height="100%" xmlns="http://www.w3.org/2000/svg">`.

**What NOT to do:**
- Do NOT use framer-motion in this component — it's a pure SVG+CSS component
- Do NOT hardcode hex colors — use `currentColor` for pattern strokes
- Do NOT hardcode opacity values — read from CSS custom properties
- Do NOT use a single shared `id` prefix — must use `useId()` per instance

**Part A: Add CSS keyframes to globals.css**

Add the following to `app/globals.css` inside the `@layer components` block (after the existing `.fade-in-scroll` rules):

```css
.hero-pattern-draw {
  stroke-dasharray: var(--hero-path-length, 2000);
  stroke-dashoffset: var(--hero-path-length, 2000);
  animation:
    hero-draw 1.2s cubic-bezier(0.0, 0.0, 0.2, 1) forwards,
    hero-settle 0.8s cubic-bezier(0.4, 0.0, 0.2, 1) 1.2s forwards;
  opacity: 0.13;
}

@keyframes hero-draw {
  to { stroke-dashoffset: 0; }
}

@keyframes hero-settle {
  to { opacity: 0.06; }
}

@media (prefers-reduced-motion: reduce) {
  .hero-pattern-draw {
    stroke-dashoffset: 0;
    opacity: 0.06;
    animation: none;
  }
}
```

The `@media (prefers-reduced-motion: reduce)` block must be placed INSIDE `@layer components` so it doesn't get overridden by specificity issues.

**Part B: Create GeometryAccent component**

Create `components/ui/GeometryAccent.tsx` as a `'use client'` component.

**Props interface:**
```typescript
interface GeometryAccentProps {
  className?: string;
}
```

**Implementation details:**

1. Use `useRef` to get a reference to the SVG `<path>` element.
2. Use `useEffect` to read `path.getTotalLength()` at runtime and set `--hero-path-length` as an inline CSS custom property on the SVG element. This avoids hardcoding the path length and survives design changes.
3. Use `useId()` for any internal SVG IDs (if needed for patterns within the hero).

4. The SVG path itself: Create a fractal-like geometric path that represents the "engineering blueprint" aesthetic. The path should be a recursive grid structure — similar to GridPattern but drawn as a single continuous `<path>` so the stroke-dashoffset draw technique can animate it as one line being drawn.

   Design the path as a grid-like structure in a viewBox of approximately `0 0 600 600`. The path should trace:
   - A primary outer rectangle
   - Internal subdivisions at 2-3 recursion levels
   - The total path should be complex enough to fill 1-1.5 seconds of draw time at a reasonable pace

   Use `stroke="currentColor"` and apply the `hero-pattern-draw` CSS class to the path.

5. Wrap in a positioned container:
   - Outer div: `absolute inset-0 overflow-hidden pointer-events-none`, `aria-hidden="true"`
   - Apply CSS mask-image: `radial-gradient(ellipse 80% 80% at 50% 50%, black 40%, transparent 100%)` — the hero uses full-section coverage with center fade, not corner accent

6. The SVG must use `preserveAspectRatio="xMidYMid slice"` to cover the full container area.

**What NOT to do:**
- Do NOT use framer-motion for the draw animation — CONTEXT.md explicitly locks hero to CSS keyframes + SVG only
- Do NOT use `motion.path` with `pathLength`
- Do NOT set a fixed path length — read from `getTotalLength()` at runtime
- Do NOT forget the prefers-reduced-motion guard (handled by the CSS class `.hero-pattern-draw`)
