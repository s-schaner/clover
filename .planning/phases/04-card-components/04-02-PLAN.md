   - Each tag: `<span key={tag.label}>` with classes `text-xs font-mono text-on-surface-subtle border border-on-surface-subtle/30 px-2 py-0.5`
   - No border-radius on tags — sharp corners per design system

**Card container:**

- No border-radius — sharp corners

- No border-radius classes (no rounded-*)
- Tags use `font-mono` for JetBrains Mono (code accent font)
- Pass `className` through to HoverLift so parent can add `h-full` for equal-height grids
