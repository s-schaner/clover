  <action>
1. **Update next.config.ts** with bundle optimization:
```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  experimental: {
    optimizePackageImports: ['lucide-react'],
  },
};

export default nextConfig;
```
This tree-shakes lucide-react (which has hundreds of icon exports but we only use Menu and X).

2. **Run production build:**
```bash
npm run build
```
Verify it completes without errors. Note the build output — check for any warnings about large first-load JS bundles (threshold is typically 100kb).

3. **Start production server:**
```bash
npm run start
```
This serves the optimized production build on localhost:3000.

4. **Run Lighthouse CLI audit** (must run against production build, NOT dev server):
```bash
npx lighthouse http://localhost:3000 --output=json --output-path=./lighthouse-report.json --chrome-flags="--headless --no-sandbox" --preset=desktop
```
Parse the JSON output for the performance score. The target is 90+.

5. **Analyze Lighthouse results:**
   - If performance score >= 90: Success. Note the exact score and any opportunities.
   - If performance score < 90, check which metric is failing:
     - **TBT (Total Blocking Time) too high:** This means framer-motion hydration is heavy. Implement LazyMotion refactor:
       - Create a client wrapper component that provides `<LazyMotion features={domAnimation} strict>`
       - Update layout.tsx to wrap children in this LazyMotion provider
       - In FadeInOnScroll.tsx, StaggerChildren.tsx, HoverLift.tsx, GeometryAccent.tsx: replace `import { motion } from 'framer-motion'` with `import { m } from 'framer-motion'` and change all `motion.div` / `motion.path` to `m.div` / `m.path`
       - Rebuild and re-run Lighthouse
     - **LCP too slow:** Check if hero h1 is the LCP element. It should be SSR'd (Server Component). If not, investigate.
     - **CLS too high:** Check if FadeInOnScroll initial opacity:0 is causing layout shifts. Usually not, since opacity changes are not layout shifts.

6. **Verify font loading:** In Chrome DevTools Network tab on the production build, confirm:
   - No requests to fonts.googleapis.com or fonts.gstatic.com (next/font self-hosts)
   - Font files served from /_next/static/media/
   - No FOUT (Flash of Unstyled Text) visible on hard refresh

7. **Clean up:** Remove lighthouse-report.json after analysis (do not commit it). Stop the production server.
