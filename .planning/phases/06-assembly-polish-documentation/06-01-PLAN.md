The StaggerItem `columns={4}` prop stays the same — the diagonal delay math is based on max columns, not current breakpoint.

2. **HeroSection.tsx** — Start the dev server (`npm run dev`). Open Chrome DevTools at 375x667 (iPhone SE dimensions). Visually verify the hero section: h1 tagline, p subheading, and CTA link must ALL be visible within the viewport without scrolling. If they do NOT fit:
   - In globals.css, reduce `--text-hero` from `clamp(3rem, 8vw, 7rem)` to `clamp(2.25rem, 7vw, 7rem)` (minimum drops from 48px to 36px)
   - Reduce `--section-padding-y` from `clamp(5rem, 10vw, 10rem)` to `clamp(3.5rem, 8vw, 10rem)` (minimum drops from 80px to 56px)
   - If still not fitting, also add `min-h-[100dvh]` instead of `min-h-screen` on both the SectionWrapper className and the inner div className in HeroSection.tsx (dvh accounts for mobile browser chrome)
   - If it DOES fit already, make no changes to HeroSection.tsx or globals.css hero token

3. **PortfolioSection.tsx** — At 375px width, check the filter pills row. The current `flex flex-wrap gap-2 justify-center mb-12` should wrap the 6 pills to 2-3 rows. If the wrapping looks clean (pills are evenly distributed, no single orphan pill on last row), leave as-is. If wrapping looks messy (irregular row lengths, cramped), change to horizontal scroll: `flex gap-2 overflow-x-auto pb-2 mb-12 [-webkit-overflow-scrolling:touch] [scrollbar-width:none] [&::-webkit-scrollbar]:hidden` and REMOVE `flex-wrap` and `justify-center`.

4. **Horizontal overflow check** — At 375px in DevTools, run in the console: `[...document.querySelectorAll('*')].filter(el => el.offsetWidth > document.body.offsetWidth)`. If any elements are returned, fix them (likely by adding `overflow-hidden` to the offending parent or adjusting fixed-width SVGs).

5. **Section transitions** — Scroll through the full page at 1440px. The dark-light-dark-light-dark rhythm (Hero dark -> Services light -> Portfolio dark -> Team light -> Contact dark) should produce clean visual boundaries. If the hard cuts between sections look abrupt, add a thin geometric divider in globals.css:
```css
@layer components {
  .section-dark + .section-light,
  .section-light + .section-dark {
    position: relative;
  }
  .section-dark + .section-light::before,
  .section-light + .section-dark::before {
    content: '';
    position: absolute;
    top: 0;
    left: 50%;
    transform: translateX(-50%);
    width: min(80%, 80rem);
    height: 1px;
    background: linear-gradient(to right, transparent 0%, currentColor 25%, currentColor 75%, transparent 100%);
    opacity: 0.1;
  }
}
```
Do NOT use clip-path — it clips absolute-positioned GridPattern/GeometryAccent children. If hard cuts look fine (which is likely for B&W), skip the divider entirely.

   - 768px: Team grid is 4 columns, Services/Portfolio are 2 columns, navigation shows desktop links (md:flex threshold)
