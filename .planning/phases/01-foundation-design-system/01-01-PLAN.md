Confirm it uses `@tailwindcss/postcss` (not the legacy `tailwindcss` plugin). The correct content is:
```js

  plugins: {
```

Step 5 — Verify next.config.ts:
Ensure it does NOT contain `eslint: {}` (removed in Next.js 16) or `experimental: { turbopack: ... }` (turbopack is now top-level/default). A minimal config is fine:
```ts

const nextConfig: NextConfig = {};
export default nextConfig;
```

Step 6 — Verify package.json scripts:
Ensure the `"lint"` script does NOT use `"next lint"` (removed in Next.js 16). It should use `"eslint ."` or `"eslint"` directly. If `"next lint"` is present, replace it with `"eslint ."`.
