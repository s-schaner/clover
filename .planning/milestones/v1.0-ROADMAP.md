# Milestone v1.0: Skeleton Site

**Status:** SHIPPED 2026-02-23
**Phases:** 1-6
**Total Plans:** 18

## Overview

The Clover Labs skeleton website is built in a strict dependency-driven order: design tokens and data contracts first, then layout shell and navigation, then visual primitives and animation vocabulary, then UI card atoms, then the five content sections, and finally assembly and polish. Each phase unblocks the next. The result is a pure black-and-white, geometric fractal-accented Next.js site that radiates engineering credibility — a resolved design language ready to evolve into the mature production site.

## Milestone Summary

**Key Decisions:**
- Next.js 16 + TypeScript strict + Tailwind CSS v4 + Framer Motion 12 as stack
- Pure B&W design — no accent colors; geometric fractal SVG patterns as sole visual texture
- Four-leaf clover brand mark (not circuit board) as signature visual identity
- Hybrid single-page scroll structured for future multi-page split
- All content hardcoded in lib/constants.ts — real owner names from day one
- @theme inline required for font family var() references in Tailwind v4
- clamp() spacing tokens in :root (not @theme) — Tailwind cannot statically analyze clamp()
- CSS keyframes for hero animation (not Framer Motion) — performance and SSR compatibility
- HoverLift built into card atoms — prevents double-wrapping in section components
- data-scroll-behavior="smooth" is Next.js 16 router signal only — CSS rule required separately

**Issues Resolved:**
- Missing CSS scroll-behavior:smooth rule (Phase 2 verification caught, fixed before Phase 3)
- Nested <main> elements (layout.tsx + page.tsx both had <main>, fixed in Phase 5)
- framer-motion 12 staggerChildren deprecation (replaced with manual diagonal delay calculation)
- Stale grid-cols reference in COMPONENTS.md (Phase 6 fix for lg → md breakpoint change)

**Issues Deferred:**
- Team member roles pending owner confirmation (placeholder "Co-Founder & Principal Engineer")
- Company email pending confirmation (placeholder hello@cloverlabs.io)
- Lighthouse 90+ score pending manual Chrome DevTools audit
- Portfolio items have intentional placeholder outcome metrics

**Technical Debt:**
- PATTERN_CONFIG and SECTIONS constants exported but never imported (orphaned dead code)
- NAV_HEIGHT_PX and --nav-height manually synchronized (no programmatic binding)
- ContactForm focus:outline-none diverges from global :focus-visible pattern
